# Portfolio Risk Analysis

This project analyzes the risk of an equity portfolio using Python.

## Key Features
- Calculated daily returns and annualized volatility
- Built an equal-weighted portfolio
- Computed 95% and 99% Value at Risk (VaR)
- Performed stress testing under market downturn scenarios
- Visualized return distributions and risk metrics

## Tools Used
- Python (pandas, numpy, matplotlib)
- yfinance (data source)

## Key Insights
- Identified the most volatile assets in the portfolio
- Estimated potential losses under extreme market conditions
- Demonstrated how diversification impacts overall risk
